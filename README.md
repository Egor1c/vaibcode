# Гостиная

Лёгкий домашний экран для webOS с эстетикой Apple TV: авторский пейзаж, крупные карточки сервисов, управление стрелками, OK, Back и указателем. Работает без внешних шрифтов, картинок, аккаунта или сетевого сервера. Настройки карточек сохраняются только на устройстве.

## Установка на телевизор

1. В Developer Mode включите Dev Mode и Key Server. Mac и телевизор должны быть в одной сети.
2. Подключите телевизор через webOS Dev Manager (пользователь `prisoner`, порт `9922`, актуальный IP и Passphrase с экрана ТВ). Не публикуйте Passphrase.
3. В Apps нажмите **Install**, выберите `com.vaibcode.livingroom_1.0.0_all.ipk` из `dist` и дождитесь завершения.
4. Найдите **Гостиная** в приложениях ТВ или нажмите Launch в Dev Manager.

Приложение устанавливается отдельно: прошивка, системный Home и существующие приложения не изменяются. Автозапуск не реализован. Developer Mode имеет ограниченный срок; продлевайте сессию до истечения. При отключении/истечении режима разработчика установленные через него приложения могут быть удалены.

## Сервисы

Карточки — ярлыки, а не встроенные видеоплееры. Установите нужные кинотеатры из магазина телевизора и войдите в свои аккаунты. Их доступность зависит от региона, модели, подписки и поддержки сервиса. Наличие карточки не означает доступность приложения (включая Netflix и more.tv).

ID сторонних приложений в `app/app.js` — начальные значения, которые необходимо сверить на конкретном ТВ. В **⚙ → настройки экрана** можно скрыть ненужные сервисы и изменить ID на точный ID установленного приложения. Для обнаружения ID используйте доступную информацию в Dev Manager; если системные приложения там не отображаются, потребуется отдельно проверить ID на ТВ. При ошибке запуска показывается сообщение, успех не имитируется. Пустой список Dev Manager не доказывает отсутствия системных приложений.

ТВ, HDMI и настройки также запускаются через API webOS; наличие HDMI 3 и права на системные приложения проверяются на конкретном телевизоре. VPN не входит в приложение.

## Разработка и сборка

Нужен Node.js 20+. Из существующего checkout (создавать worktree не требуется):

```sh
npm ci
npm start
```

Сборка официальным webOS CLI:

```sh
npm run build
```

Результат — `dist/com.vaibcode.livingroom_1.0.0_all.ipk`. Для браузерных проверок нужен Chromium:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Тесты проверяют навигацию, сохранение настроек, ошибки запуска, передачу ID в mock API и размеры экрана. Браузерный mock не заменяет проверку запуска приложений, Back и совместимости на физическом ТВ.
